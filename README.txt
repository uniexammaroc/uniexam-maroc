UNIEXAM MAROC — QUICK START

1) This is a static website package. Open index.html locally to preview.
2) Before publishing:
   - Replace demo entries in data.js with real, verified resources and working PDF links.
   - Add your real contact email in contact.html.
   - Replace YOUR-DOMAIN.example in robots.txt and sitemap.xml with your published URL.
   - Review privacy.html and terms.html so they accurately describe your actual services.
   - Do not upload copyrighted exam papers unless you have permission or a valid legal basis.
3) Publish on GitHub Pages:
   - Create a new public GitHub repository named uniexam-maroc (or another name).
   - Upload all files and folders from this package to the repository root.
   - In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
   - The Pages URL will follow the repository owner/name.
4) Google AdSense approval is not guaranteed. Add substantial original content, real resources,
   accurate contact/privacy information, and ensure the site complies with AdSense policies.
